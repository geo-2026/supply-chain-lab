## 2. 앱 구성 (빌드 없음 : HTML + CSS + 바닐라 JS)
- **자료 탭** : 광고지·라벨(PNG로 변환, 크게 보기·PDF 원본), 부가가치 자료(개념 표 + 7쪽 이미지 + 제품별 부가가치 표·막대), 원료 가격(엑셀 내용을 제품별 표로 정리, 엑셀 원본 내려받기)
- **지도 탭** : 캔버스 세계지도(태평양 중심, Natural Earth 110m). 장소 추가(지명 검색 80여 곳 / 지도에서 직접 찍기), 역할 5종(브랜드 본사·원료 생산지·제조국·유통·판매), 구간 추가(도로/선박), 제품별 기본 경로 불러오기, 지도 이미지 자동 저장, 지도 PDF 저장
- **활동지 탭** : 시작(학생 정보·백업) → 활동 1~8 → 평가지(자기 성찰 → 발표 평가) → 제출 전 점검·PDF. 자동 저장(0.5초)·‘저장됨’ 표시, 글자 수 표시, 휴대폰에서는 표가 카드형으로 바뀜
- **이동 거리 계산(평균 기준)** : 도로 = 직선거리 × 1.3, 선박 = 주요 항로 노드(수에즈·파나마·말라카·지브롤터·희망봉 등) 그래프 최단 경로, 내륙은 가까운 항구까지 도로. 구간마다 육상 km·해상 km·합계를 구분 표시(지도 : 주황 점선 = 육상, 파란 실선 = 해상)
- **저장** : IndexedDB(localForage, 이름 `supply-chain-lab`) — 학생 단말기에만 저장. 백업 JSON 내보내기/불러오기, 모든 기록 지우기(2회 확인)
- **PDF** : html2canvas + jsPDF, A4 세로, 머리말·쪽 번호, 종이 활동지와 같은 문항·순서, 지도 이미지 포함, 지도 PDF 2쪽 합치기 선택. 파일명 `반-번호_이름_상품사슬활동지.pdf`
- **오프라인** : 서비스 워커(sw.js)로 전체 파일 캐시. 글꼴 Noto Sans KR(KS X 1001 한글 2,350자) 포함. PWA 매니페스트·아이콘

## 4. 검증한 것
- 헤드리스 Chrome(puppeteer-core) 자동 테스트 : 학생 정보 → 제품 선택 → 2-1 합계·2-2 비율 → 2-3 [확인] → 지도 기본 경로(13개 장소·7구간) → 4-2 지도 장소 불러오기·[확인] → 5-2 구간 표·지도 이미지 → 6-1 비율 → 평가 합계 → 새로고침 후 유지 → 활동지 PDF(12쪽)·지도 PDF(2쪽)·백업 JSON 다운로드 → 서비스 워커 캐시 66개. 콘솔 오류 0건
- 배포 주소에서도 같은 검사 통과(HTTP 200, 서비스 워커 활성)
- 경로 계산 검증 예 : 상하이→로테르담 약 19,900 km, 부산→LA 약 9,900 km, 리옹→서울 도로 403 + 해상 17,471 km

## 5. 재배포 방법
1. `supply-chain-lab` 폴더에서 파일 수정
2. `sw.js`의 `VERSION` 문자열을 올림(예 : scl-v1.0.1) — 학생 기기의 오프라인 캐시 갱신용
3. `git add -A && git commit -m "..." && git push origin main` → 1~2분 뒤 배포 주소에 반영
- git 사용자 설정은 저장소 로컬에 되어 있음(geo-2026). gh CLI 로그인 상태(geo-2026)

## 6. 남은 과제·아이디어 (미완)
- 휴대폰 세로 화면에서 지도가 작음 → 지도 높이를 키우거나 전체 화면 보기 추가 검토
- 실제 학생 휴대폰(안드로이드 크롬·아이폰 사파리)에서 PDF 저장·비행기 모드 동작 실기 확인 필요
- 교사용 기능(여러 학생 PDF 모아 보기 등)은 요구사항에 없어 만들지 않음
- 지명 사전·항로 노드는 필요 시 `js/data.js`의 GAZ / SEA_NODES / SEA_EDGES에 추가
