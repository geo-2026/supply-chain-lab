# 상품 사슬 탐험 — 가상 상품으로 따라가는 상품 사슬 프로젝트

2026 세계시민과 지리 수행평가용 웹앱입니다. 빌드 없이 HTML + CSS + 바닐라 JavaScript로만 만들어졌고, GitHub Pages에서 고정 주소로 실행됩니다.

- **자료** : 가상 상품 광고지 6종(data1), 가상 상품 라벨 6종(data2), 부가가치 학습자료·라벨 원료 가격표(data3)
- **지도** : 브랜드 본사 · 원료 생산지 · 제조국 · 판매 지역 표시, 운송 구간을 그리면 **육상(도로)·해상(선박) 거리를 구분해 평균 기준으로 자동 계산**
- **활동지** : 종이 활동지를 바탕으로 한 활동 1~8, 평가지(자기 성찰), 제출 전 점검, PDF 저장 (2026-10-20 2차 수정 : 자료 새 탭 보기, 2-3 A·B 입력란, 활동 5-1 삭제, 활동 7·8 구성 변경, 발표 평가 삭제 / 2026-10-21 3차 수정 : 시작 → ‘광고지’ 화면에서 제품 선택, 활동 1에 선택한 광고지 자동 표시·[확대하기] 새 탭, 활동 4 [지도 만들러 가기] 상단 이동 / 2026-10-21 3-1차 : 활동 2에도 광고지 자동 표시, 새 버전 배포 시 자동 새로 고침, 홈 [최신 버전으로 새로 고침], 서비스 워커 설치 시 HTTP 캐시 우회)

## 저장 방식
- 모든 입력은 학생 단말기의 브라우저(IndexedDB, `supply-chain-lab`)에만 저장됩니다. 서버로 보내지 않습니다.
- 최종 결과물은 `반-번호_이름_상품사슬활동지.pdf`(A4)와 `…_상품사슬지도.pdf`로 내려받습니다.
- 백업 파일(JSON) 내보내기/불러오기로 다른 기기에 옮길 수 있습니다.
- 서비스 워커로 모든 파일을 캐시하므로 한 번 접속한 뒤에는 인터넷 없이도 동작합니다.

## 이동 거리 계산 기준 (평균적인 추정)
| 구분 | 기준 |
| --- | --- |
| 도로 (육상) | 두 지점의 직선(대권) 거리 × 1.3 (평균 도로 우회율) |
| 선박 (해상) | 주요 항로 노드(수에즈·파나마 운하, 말라카·지브롤터·호르무즈 해협, 희망봉 등)를 잇는 그래프에서 최단 항로 |
| 내륙 장소 | 가장 가까운 항구까지 도로로 이동한 뒤 선박 (구간 표에 '도로+선박+도로'로 표시) |

## 폴더 구조
```
index.html            화면
manifest.webmanifest  PWA
sw.js                 서비스 워커(오프라인 캐시)
css/app.css
js/data.js            제품·원료·부가가치·지명·해상 항로 데이터
js/geo.js             거리 계산 (대권 거리, 도로 우회율, 해상 그래프 최단 경로)
js/store.js           저장소 (localForage / IndexedDB)
js/map.js             상품 사슬 지도
js/resources.js       자료 보기
js/worksheet.js       활동지 (활동 1~8, 평가지, 점검)
js/pdf.js             PDF 저장 (html2canvas + jsPDF)
js/main.js            화면 흐름
lib/                  localforage 1.10.0, html2canvas 1.4.1, jspdf 2.5.1
fonts/                Noto Sans KR (KS X 1001 한글 2,350자)
assets/ads, labels, va   광고지·라벨·부가가치 자료 이미지
assets/pdf            원본 PDF·엑셀
assets/world.json     세계 지도 (Natural Earth 110m, world-atlas)
```

※ 모든 제품·브랜드·금액은 수업용 가상 자료입니다. 실제 기업·제품과 관계없습니다.
